Không tách nghĩa theo frontend/backend.

Hai lớp có thể nói về cùng một khái niệm. Chỉ tách nghĩa khi phạm vi và mô hình khác nhau; những nhóm ở trên chưa mặc định là service hoặc bounded context đã xác nhận.

Ví dụ cần phỏng vấn: “xong” là xong gì?

Các nhãn và symbols dưới đây là đề xuất để review.

Automation · Job Run

Job kiểm PR đã chạy xong, có thể không có comment mới.

UI: “Đã chạy xong” · code đề xuất: JobRun.status = completed
Execution · Workflow Run

Công việc dự án đã có kết quả và bằng chứng đạt các tiêu chí bắt buộc.

UI: “Đạt tiêu chí” · code đề xuất: WorkflowResult.outcome = accepted
