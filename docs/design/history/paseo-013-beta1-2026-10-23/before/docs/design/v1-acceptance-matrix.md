## Evidence attached to a result

Each reported conclusion needs its tested case/criterion and scope, actual artifact/Evidence references, relevant source/config/candidate revisions, runtime/provider/environment versions, outcome/check result, and known gaps. Credentials are not evidence payloads. This is an information obligation, not an approved new database schema or a generic evidence service.

Only evidence covering the actual claim counts. Local/scripted checks validate harness logic under injected conditions; live 0.12 observations validate the native behavior exercised. Existing 0.11.1 spikes, standalone 0.12 recovery fixtures, HTML assertions, configured bindings and source presence retain their original limits. They are not aggregated into a V1 pass by counting tests.
