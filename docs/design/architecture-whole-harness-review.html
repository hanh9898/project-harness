4. Context, methods và sự thật được lưu

Instructions & selected methods

Versioned instructions + common rules + Assignment/task/criteria. Explicit Skill name/source; Principles auto/fixed/hybrid. Worker mới mặc định dùng fresh Session, continuation cùng Assignment giữ Session.

Inherited Skills vẫn có thể được discover. Không hứa isolation, loại hết native inputs hoặc biết universal instruction precedence.

Learned Knowledge

Notes có source/scope/qualification/history; retrieval theo nhu cầu. Source drift/contestation → cần applicability recheck, bỏ default automatic loading, giữ lịch sử có qualification.

Note không thay authoritative requirement/criteria. Nâng thành instructions/Skill/workflow đi qua candidate/check/activation.

Versioned assets · Git

Plugin source, common/project-specific instructions/definitions, methods do harness sở hữu, programs/jobs/evals.

External pstack/matt/native installations giữ owner riêng. Selected upstream patch là local candidate; không tự import hoặc chờ upstream duyệt để dùng local.

Active state · SQLite + artifacts

Owner-held config revisions, inbox/work, operations/checkpoints/cursors và active refs. Artifacts lớn có references/digests.

Intent trước effect; reconcile uncertain responses. Live event không là durable journal; không hứa exactly-once external effects.

5. Deep module boundaries

Mở mỗi owner để xem trách nhiệm. Tên module được chốt; method/schema/protocol vẫn cần engineering và contract proof.

AgentDefinitions

Catalog/definition revisions, role/instruction/Skill/Principle bindings và resolve cấu hình hợp lệ. Không sở hữu native profiles hay tự cấp quyền dispatch.

Work

Hai inbox, Actions/Limits/Delegation Policy, receipts/admission/Assignments/dispatch, timers/checkpoints, cycle/wake/Pause và reconcile. Quyền bị thu hồi không được giữ nhờ snapshot cũ.

WorkflowPrograms

Chaining, routing, parallelization, orchestrator-workers và evaluator-optimizer có thể ghép/lồng. Validate contracts/bounds cho registered blocks; không thực thi arbitrary generated code để lách release.

Triggers

Code jobs/cadence/cursors, occurrences/delivery và bounded missed/overlap/catch-up. Native agent cadence do Paseo sở hữu; retry/deadline timers do Work sở hữu.

Criteria

Tiêu chí authoritative có scope/revision, Evidence và Verdict. Agent hết Turn hoặc trả Outcome không tự chứng minh pass.

Knowledge

Learned-note lifecycle, scoped retrieval/history/qualification và applicability recheck. Không là generic Memory platform, requirements store hay service/database mới.

Analytics

Sourced queries/comparisons/Saved Views, drill-down cho dashboard/retro. Missing không bằng zero; operational comparison không tự chứng minh causation.

Releases

Candidate-specific checks, authority/compatibility, activation/observed state và independent compatible recovery. Code rollback không tự rollback database.

6. Management UI và native boundary

Chat là interface chính

Nghiệp vụ qua Project Orchestrator; phát triển harness qua Harness Engineering. Panel phục vụ Orchestrators menu, Agents/Limits/Actions/Automations, harness inbox, monitoring và deep Analytics.

Installed/bound/selected/checked/active là các quan sát khác nhau. Existing owner views cung cấp provenance; không thêm asset CRUD screen chỉ vì có asset mới.

Lifecycle có chủ đích

Open Session mở chat hiện có; Spawn/Replace do người dùng chủ động. Restart reconcile trạng thái đã lưu, không tự bật jobs bị tắt hoặc tạo orchestrator thay thế.

Stop native ≠ durable Pause. Pause không tự hủy workers/effects; coordinated native cadence phải hiện pending/confirmed đúng thực tế.

7. Đã chốt phạm vi; còn phải chứng minh khi triển khai

Engineering/proof còn lại: installer/distribution; SDK/provider pins; interpreter/schema/transactions; MCP auth/transport; scheduler bridge; wake/cancel/fencing; evaluator datasets/calibration và metric formulas; UI projections/localization; installed recovery artifacts và provider parity.

Spikes cô lập không là nghiệm thu end-to-end V1. Graph relationship inferred/unknown không tự được nâng thành invariant. Nếu capability thực tế xung đột requirement, quay lại quyết định liên quan.
