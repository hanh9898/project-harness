Giống ở agent definitions và delegation.
Khác ở runtime, ownership và vòng cải tiến.

Claude Managed Agents là harness do Anthropic vận hành. Agent Team của mình đang là đề xuất tên UI cho catalog vai trò/năng lực trong một Paseo Plugin; hai phạm vi này không đồng nhất. Overview

Cột bên phải là thiết kế Project Harness đã bàn, chưa phải capability production đã triển khai.

1. Definition khác runtime instance

Managed Agents

Agent là config có version; Session tham chiếu Agent và Environment.

Project Harness

Agent Definition tham chiếu native Paseo profile; Assignment giao việc và liên kết tới Agent Session.

Giống cách tách định nghĩa và lần chạy; không phải mapping một-một mọi entity. Agent setup

2. Catalog và quyền delegation

Managed Agents

Tách subagents, dynamic workflows và advisor. Có danh sách predefined agents và tùy chọn inline agents.

Project Harness

Đã có catalog role/procedure/Skills/Principles. Policy cho từng orchestrator được giao cho ai, bằng cách nào còn cần cụ thể hóa.

Multiagent orchestration

3. Program điều phối nhiều agent

Managed Agents

Claude viết program, server chạy nền, fan-out, gom kết quả và xử lý nhánh/vòng lặp.

Project Harness

Yêu cầu năm pattern tổ hợp; code runtime giữ admission, checkpoint và bằng chứng. Workflow được validate/pin trước chạy.

Không lồng Run khác với không lồng được composition. Workflow runs

4. Hạ tầng và ownership

Managed Agents

Anthropic vận hành harness; có environment cloud hoặc self-hosted sandbox. Self-hosted sandbox không chuyển toàn bộ agent loop về máy mình.

Project Harness

Paseo host local; hai orchestrators cho dự án và phát triển harness; đa provider qua native profiles. Host tắt thì không có cloud chạy thay.

Self-hosted sandboxes

5. Skills, tools và môi trường

Managed Agents

Agent khai tools/MCP/Skills; context agent riêng nhưng có thể dùng chung filesystem của Session.

Project Harness

Skills chỉ định tên/nguồn, Principles auto/fixed/hybrid. Worker ghi dùng worktree riêng theo thiết kế; tool/quyền phải kiểm qua adapter, không tin prompt.

MCP và shared sandbox · Permission policies

Managed Agents

Outcomes có rubric/grader; Dreams tạo memory store mới để review.

Project Harness

Daily retro cải tiến workflow và chính plugin: UI/runtime/Jobs/schema/Skills. Candidate, kiểm theo ảnh hưởng, fix-forward/recovery là phạm vi riêng.

ƯU TIÊN 1 · CỤ THỂ HÓA

Delegation Policy cho từng orchestrator

Catalog trả lời “có ai”; policy trả lời “orchestrator này được dùng ai, bằng cách nào”. Giới hạn vào Agent Definitions đã đăng ký là điểm khởi đầu dễ kiểm chứng.

  • Allowed Agent Definitions.
  • Delegate / workflow / consult tùy nhu cầu.
  • Inline definition mặc định tắt theo đề xuất local; mở khi có lý do và vẫn qua validation/pin.
Khác default Managed Agents: inline được bật mặc định. Nguồn
ƯU TIÊN 2 · GIỮ & LÀM RÕ

Effective config của mỗi Assignment

Ghi Agent Definition revision, native profile đã resolve, Skill sources/digests, Principles đã chọn và output contract. Thay config không sửa ngầm Assignment cũ. Skill ngoài bị sửa thì phát hiện drift; không tuyên bố đã snapshot/isolate provider.

Managed session version pinning
ƯU TIÊN 3 · CẦN KIỂM ADAPTER

Tool requirements khác credentials

Definition/role mô tả capability cần có; credentials là reference được resolve lúc chạy. Với custom tool, nơi thực thi phải kiểm quyền. Không thêm một editor provider/model trùng Paseo.

MCP connector · Execution owner

Config sketch · chỉ là giả mã của harness

agentDefinition:
  profileRefs: [native-primary, native-fallback]
  skills: [selected-skill-refs]
  principlePolicy: auto | fixed | hybrid

teamPolicy:                     # đề xuất mới
  orchestrator: project
  allowedDefinitions: [investigate, implement, verify]
  modes: [delegate, workflow]
  inlineDefinitions: disabled

Không phải API/schema Paseo hay Managed Agents. Budget, expected revision, secret resolution và kiểm compatibility nằm sau interface; không bắt người dùng điền tất cả mỗi task.

Học thêm, chưa cần thêm settings

  • Consultation khi cần ý kiến; worker khi cần giao phần việc. Managed advisor là cơ chế riêng và có thể redacted, không giả native Paseo có cùng API.
  • Reconnect: đối soát event history và blockers; callback chỉ đánh thức. Không copy replay protocol sang Paseo khi chưa kiểm.
  • Giữ Outcome, Verdict, quyền activation và trạng thái runtime riêng.
  • Scheduled deployment không thay bộ lịch code jobs với overlap/missed policy của mình.

1 · Project Orchestrator nhận yêu cầuChat hoặc code polling có delta. Code dedupe và ghi Work Item trước khi giao việc.
2 · Chọn specialist trong tập hợp lệĐọc when-to-use và contract. Việc nhỏ có thể tự làm; không tạo cả đội mặc định.
3 · Chọn cách phối hợpConsult để xin ý kiến; delegate một phần việc; workflow program khi cần nhiều bước/nhánh/agent. Agent quyết định tại các điểm được code cho phép.
4 · Validate và pin trước dispatchKiểm authority, capability, budgets và definition/profile/Skill refs. Thiếu capability thì chặn hoặc tạo yêu cầu liên kết sang Harness Engineering Orchestrator.
5 · Runtime chạy, agent trả OutcomeContext theo Assignment; worker ghi trong worktree riêng khi cần. Effect mất phản hồi phải reconcile trước fallback/retry.
6 · Đánh giá bằng EvidenceVerify độc lập theo candidate và rubric. Turn kết thúc hay program completed chưa đủ kết luận toàn yêu cầu đạt.
7 · Học và phát hành thay đổi harnessDaily retro có bằng chứng → candidate config/Skill/workflow/code → kiểm Fast/Deep path → activation → quan sát. Giữ/lùi bộ nhớ không thay protocol release code/schema.
